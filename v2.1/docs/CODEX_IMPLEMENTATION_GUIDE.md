# 《文军长征：建德四十五日》Codex 开发实施指导书 V1.2｜双地图、临时教室与周考GPA

> 目标仓库：`YGBDCF/wenjun-jiande`（Ren'Py）。本文件不是概念提案，而是 Codex 应逐项执行的产品规格、内容规格与验收标准。

## 文档结构

1. 总要求与现有仓库兼容；
2. 两张大地图联动、Day7第五章门控与地图翻新；
3. 沈砚舟人设、定量属性和活动门槛；
4. 45日四时段、天气、强制返宿与事件引擎；
5. 临时教室、每周周考、5.0 GPA与考试诚信；
6. 45日固定时间轴与Day10-Day20《浙大日报》任务链；
7. 八地点基础互动与83个写定随机事件；
8. 竺可桢偶遇、Day45“二问”与吉安—泰和彩蛋；
9. Codex提交顺序、自动化测试、人工验收与史实边界。

## 0. 不可违背的总要求

1. 现有六章内容、图片与可运行标签不得删除；新系统采用增量接入。
2. 历史大方向不可由玩家改写。玩家只能影响人物关系、资源状态、过程难度、札记内容与彩蛋呈现。
3. 建德篇以 1937-11-12 为 Day 1、1937-12-26 为 Day 45，首尾均计，共 45 个自然日。
4. 每日四个时间格：早晨、中午、晚间、深夜；前三格可主动行动，深夜不可行动。故全篇 180 个时间格、135 个主动行动回合。
5. 晚间行动结束后无条件强制回到学生宿舍；深夜结算时 `current_location` 必须为 `dormitory`。
6. 两张大地图必须共享同一套存档状态，并通过章节完成旗标驱动建德地图翻新：Day 1-Day 6 的正式学习全部发生在孔庙，建德地图原有空地仅作锁定地标；Day 7 早晨强制解锁并完成第五章，章节完成后原空地替换为“临时教室”，正式课程、复习和考试自此迁入教室。Day 10-Day 19 开展《浙大日报》筹备任务，Day 20 固定解锁第六章与报纸系统。第 38 日固定触发“课程暂不结束”；第 41 日物资先行；第 43 日起分批撤离；第 45 日最后撤离。
7. 竺可桢“二问”必须作为不可改写的中文常量：

   **“诸位在校，有两个问题应该自己问问：第一，到浙大来做什么？第二，将来毕业后要做什么样的人？”**

8. 二问原为 1936 年开学典礼语境；将其置于第 45 日离城彩蛋，属于明确标注的艺术移置，不得伪称为建德现场原话。
9. 每次提交必须保持 Ren'Py 项目可启动；不得一次性重写所有文件。

## 1.1 两张大地图的链接与解锁逻辑（最高优先级）

### 1.1.1 地图定义

项目必须保留并链接两张不同职责的大地图：

1. **西迁章节大地图**（代码ID：`chapter_world_map`）
   - 展示第一至第六章的历史章节节点。
   - 负责章节解锁、章节剧情回放、史实资料入口与章节完成状态。
   - 第五章、第六章不是在建德地点菜单中直接播放，而是在此地图解锁后进入。

2. **建德生活大地图**（代码ID：`jiande_exploration_map`）
   - Day1-Day6展示孔庙、林场、校务办公处、民居、当铺、梅城码头、学生宿舍七个地点及一块锁定空地；完成第五章后空地替换为第八地点“临时教室”。
   - 负责45日生活探索、天气、成长、考试、任务链、随机事件与深夜返宿。

两张地图不是两个独立存档，也不是两套互不相干的流程。它们必须读写同一组 `campaign_day`、`campaign_period`、章节完成旗标、人物关系、天气与世界状态。

### 1.1.2 地图之间的入口

- 章节大地图设置固定入口：**“进入建德·梅城”**。
  - 首次进入：调用 `jiande_campaign_bootstrap`，从 Day 1 早晨开始。
  - 已开始战役：返回当前 Day、当前时段的建德大地图，不重置进度。
- 建德大地图设置固定入口：**“西迁纪事”**。
  - 点击后返回章节大地图，展示新解锁章节和史料节点。
- 章节大地图设置 **“返回梅城生活”** 按钮。
- 两张地图之间的普通切换**不消耗时段、不改变天气、不重新抽取随机事件**。
- 深夜阶段、强制返宿演出、固定剧情不可中断阶段，地图切换按钮必须隐藏。
- 为防止读档刷事件，某一时段已抽取的地点事件必须先缓存；往返两张地图后仍返回同一事件。

### 1.1.3 进入建德战役的前置

推荐在旧章节流程中完成第四章后，于章节大地图解锁“进入建德·梅城”。若开发版允许直接测试，可另设开发按钮，但正式版必须保留章节衔接。

### 1.1.4 Day 7 固定开启第五章，不允许拖延到 Day 10

“玩满6天”必须按**完成6次深夜结算**计算，而不是点击18次地点按钮或直接修改日期变量。

- Day 6 晚间行动结束后强制返宿并完成深夜结算。
- 结算完成：`days_completed = 6`、`chapter5_unlocked = True`，进入 Day 7 早晨。
- Day 7 第一次显示建德地图前，播放固定提示：

> 【西迁纪事更新】第五章：“黑板挂在我的胸前”已经解锁。完成本章后，梅城将启用新的临时教室。

- Day 7 在玩家进行第一项自由地点行动之前，必须进入章节大地图并完成第五章。
- 第五章属于固定史实剧集，不消耗时间格；完成后仍返回 Day 7 早晨。
- 正式版不允许玩家把第五章拖到 Day 8 以后，因为 Day 8 是第二周首日，必须在新教室举行第一次正式周考。
- 开发模式可提供 `dev_skip_chapter5`，但跳过时也必须执行同一组解锁旗标与地图替换。

```renpy
label day7_chapter5_gate:
    if campaign_day == 7 and not chapter5_completed:
        $ chapter5_unlocked = True
        $ in_forced_story = True
        call enter_chapter5_episode
        $ in_forced_story = False
    return
```

### 1.1.5 第五章剧集不得消耗建德回合

第五章从章节大地图进入。进入时保存日期、时段、天气和已缓存事件；完成后原样返回：

```renpy

    $ episode_return_period = campaign_period
```

章节剧集与开教室过场均不得调用 `advance_period()`，不得增加 `action_count`，不得重抽天气。

### 1.1.6 建德地图翻新：空地变为临时教室

#### A. Day 1-Day 6 的地图状态

- 地图版本：`map_visual_phase = "pre_classroom"`。
- 孔庙承担全部正式课堂、摸底测验、答疑与晚课。
- 林场、校务办公处、民居、当铺、码头、宿舍仍可用于生活、校务、物资和人物任务；“Day7之前都在孔庙学习”指**所有正式学习活动只在孔庙发生**，并非其余地点全部关闭。
- 地图上的原空地显示为不可点击地标：`空地｜尚未启用`。
- 点击空地仅显示：`此处尚未整理，堆着木料、旧桌脚与未拆的绳索。` 不推进时段。

#### B. 完成第五章后的固定开教室演出

开教室的原因必须通过连续镜头呈现，而不是一句“新地点已解锁”：

1. 孔庙课堂拥挤，不同班级在同一时段争用桌凳与黑板。
2. 降雨会使廊下板书受潮，北风会吹乱讲义。
3. 防空警报后，桌凳、点名册和教学器材需要更稳定的收拢与复归位置。
4. 孔庙本有自身用途，长期占用并非妥善之策。
5. 章用“走到哪里，课就上到哪里”的精神，使师生意识到：既要能移动，也要有一处能够持续收纳课程秩序的临时讲堂。

固定对白（艺术加工）：

> 校务人员：“孔庙可借一时，却不能使各班日日相冲。警报一响，桌凳、讲义、点名册皆要重新收拢。”
>
> 顾明川：“空地上的木料已经分好。立柱、遮雨、固定黑板，先搭出一间能上课、能收卷子的讲堂。”
>
> 许南枝：“不是为了有一座体面的房子，是为了下一次铃响时，大家知道应当回到哪里。”

说明：原空地变为临时教室属于游戏化艺术加工，不得写成校史中有确切日期和原址的新建工程。演出应表明材料整理和准备已在前六日逐渐完成，Day7只是集中呈现与启用，不是数小时内凭空建成。

#### C. 地图资产与热点替换

```renpy
screen jiande_exploration_map():
    if map_visual_phase == "pre_classroom":
        add "images/maps/jiande_map_pre_classroom.webp"
        imagebutton:
            idle "images/maps/hotspot_vacant_lot_idle.webp"
            hover "images/maps/hotspot_vacant_lot_hover.webp"
            action Show("locked_location_notice", text="空地尚未整理。完成第五章后启用。")
    else:
        add "images/maps/jiande_map_post_classroom.webp"
        imagebutton:
            idle "images/maps/hotspot_classroom_idle.webp"
            hover "images/maps/hotspot_classroom_hover.webp"
            action Jump("classroom_hub")
```

完成第五章后必须发生：

- `classroom_unlocked = True`
- `map_visual_phase = "post_classroom"`
- 原空地热点永久移除，替换为“临时教室”热点。
- 地图其他道路、七个原地点的位置、天气覆盖层与两张大地图入口保持不变，让玩家清楚辨认是同一座梅城发生了变化。
- 地图首次翻新时播放2-4秒局部推镜：空地→木柱→黑板→课程表；之后不再重复。
- 孔庙不消失，而转为讲座、补课、史地讨论、章用人物线和恶劣天气备用教学点。

#### D. Day 8 起的正式学习迁移

- Day 8 及以后，所有“正式课程”“周考”“阅卷”“考试复盘”只能在临时教室发生。
- 孔庙的普通“随堂听讲”替换为“专题讲座/温习旧课/碑廊讨论”。
- 第五章完成前，任何 `location == classroom` 的事件不得进入事件池。
- 若旧存档在 Day 8 仍为 `classroom_unlocked == False`，视为迁移兼容异常：自动补设章节完成旗标并播放开教室演出，禁止在不存在的地点考试。

### 1.1.7 Day 10-Day 19：《浙大日报》筹备任务链

Day 10 早晨固定开启任务链：**“在杂音中求其真”**。任务的历史结果不可失败：《浙大日报》仍会在 Day 20（1937年12月1日）创刊；玩家的完成度决定其本人参与程度、创刊时的资源、初始公信和后续事件质量。

筹备界面显示：`情报委员会筹备：0/7`。七项任务分布于建德大地图：

| ID | 地点/时段 | 任务名 | 核心内容 | 类型 |
|---|---|---|---|---|
| NEWS_PREP_01 | 校务办公处·早/中 | 情报委员会的缺口 | 接受抄录职责，确认消息必须注明来源 | 核心 |
| NEWS_PREP_02 | 林场·中午 | 架起收音天线 | 借木杆与绝缘材料，改善收音条件 | 核心 |
| NEWS_PREP_03 | 当铺·中/晚 | 纸墨有数 | 通过登记、借用与交换筹集纸墨 | 核心 |
| NEWS_PREP_04 | 学生宿舍·晚间 | 工读生名册 | 招募抄写、校对、分送人员，排定轮值 | 核心 |
| NEWS_PREP_05 | 民居·中/晚 | 城里人想知道什么 | 访问居民，记录交通、亲友与战况需求 | 加分 |
| NEWS_PREP_06 | 孔庙·晚间 | 一字之差 | 完成标题、否定词、地名与数字校对训练 | 加分 |
| NEWS_PREP_07 | 梅城码头·早/中 | 迟到的纸包 | 在江雾或降雨中核对纸张、油墨与交接单 | 加分 |

#### 七项任务的固定对白与结果

**NEWS_PREP_01｜情报委员会的缺口**

开场：

> 办公桌上摊着三份广播抄稿，同一地名却有三种写法。工作人员将铅笔递给沈砚舟：“缺的不是一个写字快的人，而是一个肯在听不清时写下‘未听清’的人。”

选项：

1. `先逐份标明收听人和时刻，再比较内容`：求实+2，实务+1，完成核心旗标。
2. `挑最完整的一份誊清`：实务+1，公信-1，仍完成旗标但留下 `prep_source_weak`。
3. `说明自己尚无把握，请人示范一次`：求实+1，导师关系+1，完成旗标。

**NEWS_PREP_02｜架起收音天线**

开场：

> 顾明川抬头望着屋檐：“线再高一丈，杂音或许会少些；可木杆若固定不好，北风一起便要伤人。”

选项：

1. `先测风向，再用三点拉绳固定`：实务+2，求实+1，完成核心旗标，预报准确率+0.02。
2. `抢在天黑前把木杆竖起`：体力-1，实务+1，留下 `antenna_unstable`。
3. `因天气恶劣改在次日继续`：心志+1，任务保留，不计完成。

**NEWS_PREP_03｜纸墨有数**

开场：

> 当铺柜台后只余几刀旧纸。管理员说：“可借，但须写清何人取用、何时归还。战时缺物，更不能缺账。”

选项：

1. `登记纸张、油墨和用途`：实务+1，求实+1，居民信任+1，完成核心旗标。
2. `以个人饭票换取纸墨`：饭票-1，人望+1，完成核心旗标。
3. `先取走，待创刊后再补登记`：求实-1，纸张+2，完成旗标但触发归属争议。

**NEWS_PREP_04｜工读生名册**

开场：

> 宿舍里有人愿抄写，有人愿沿街分送，也有人担心因此耽误课程。许南枝将空白轮值表推到你面前：“不能只问谁愿意，还要问谁有余力。”

选项：

1. `按课程、体力和住处分班轮值`：实务+2，人望+1，完成核心旗标。
2. `先登记所有自愿者，之后再调`：人望+1，完成旗标，Day20疲劳+1。
3. `只挑写字最快的人`：初始效率+1，人望-1，完成旗标。

**NEWS_PREP_05｜城里人想知道什么**

开场：

> 居民围着旧壁报，有人问杭州，有人问江上交通，一位老人却只想知道外出的儿子是否还能寄信。

选项：

1. `逐项记录，并区分可报道与无法核实`：居民信任+2，求实+1，完成加分旗标。
2. `只记录最受关注的战况`：时效+1，居民信任-1，完成旗标。
3. `承诺以后都能查到`：人望暂+1，求实-2，留下 `overpromise_news`。

**NEWS_PREP_06｜一字之差**

开场：

> 黑板上写着“某地交通尚未中断”。章用擦去“不”字，整句话立刻变了意思：“新闻校对，有时只守住一个字，便是守住许多人的判断。”

选项：

1. `逐字核对否定词、数字与地名`：学识+1，求实+2，完成加分旗标。
2. `只检查标题是否醒目`：排版效率+1，公信-1，完成旗标。
3. `请许南枝与你交叉校对`：许南枝关系+1，求实+1，完成旗标。

## 3. 核心状态与存档字段

### 3.0 数值化总原则

所有随机事件的每一个玩家选项都必须造成可记录的结果。禁止出现“只有一句对白、所有数值均为0、没有旗标”的空选项。每个选项至少改变下列五类中的一类，推荐同时改变两类：

1. 玩家能力：学识、道德、实务、人望、心志；
2. 生存状态：体力、健康、保暖；
3. 人物关系：许南枝、顾明川、周顺安、导师、竺可桢印象；
4. 世界状态：课程连续度、物资完整度、居民信任、宿舍秩序、报纸公信、迁移准备；
5. 永久结果：任务旗标、事件冷却、物品、考试诚信记录、后续事件权重。

核心能力采用 **0-20** 标度，保留现有事件中 `+1/+2` 的可读性；考试时乘5归一化为0-100。生存状态采用 **0-10**。所有数值必须 `clamp`，不得越界。

| 属性 | 范围/初始 | 主要来源 | 对活动的硬影响 |
|---|---:|---|---|
| 学识 `stat_knowledge` | 0-20 / 3 | 正式课程、整理笔记、正确核对、考试复盘 | 课程题、文书核对、报纸校对、周考卷面 |
| 道德 `stat_morality` | 0-20 / 12 | 诚实、守约、公平分配、帮助弱者、拒绝作弊 | 学行分、高信任委托、借物信用、竺可桢评价 |
| 实务 `stat_practical` | 0-20 / 5 | 修缮、装卸、调度、制作器具 | 码头、林场、教室修理、天气应变 |
| 人望 `stat_reputation` | 0-20 / 8 | 帮助师生居民、履约、公共贡献 | NPC是否提供线索、借物、支线和协助 |
| 心志 `stat_will` | 0-20 / 10 | 面对坏消息、坚持课程、合理休整 | 寒潮/警报检定、晚课效率、考试稳定性 |
| 健康 `stat_health` | 0-10 / 8 | 睡眠、饮食、保暖、疾病事件 | 活动成功率、考试状态、体力恢复 |
| 体力 `stat_stamina` | 0-10 / 8 | 深夜休息、午间休整 | 决定当次行动损耗和考试疲劳惩罚 |
| 求实 `hidden_truthfulness` | -10至10 / 0 | 标明来源、承认未知、保留差异 | 报纸公信、考试学行、竺可桢彩蛋 |

### 3.3 每次周考的可玩结构

每次测试由四段构成：

1. **考前状态检查**：显示天气、体力、健康、周准备、出勤，不直接显示最终公式。
2. **三道互动题**：从本周固定题库抽取三题，答案由玩家实际选择；正确率记为0、33、67或100。
3. **学行抉择**：每周一项道德/诚信情境，例如同学传来答案、发现试卷漏页、捡到他人草稿、监考暂离。选项改变道德、求实与考试诚信记录。
4. **成绩结算**：给出卷面倾向、学行评定、总分、单次GPA、累计GPA和教师评语。

禁止把考试做成纯数值自动结算；至少三题需要玩家作答，且学行抉择不能只有唯一显然正确的按钮，应有现实代价，例如拒绝传答案会降低某位同学短期关系，但保护道德与诚信。

### 3.4 考试公式

先归一化：

```python
K = stat_knowledge * 5
M = stat_morality * 5
W = stat_will * 5
H = stat_health * 10
T = clamp(50 + hidden_truthfulness * 5, 0, 100)
A = weekly_attendance_present / max(1, weekly_attendance_possible) * 100
P = weekly_preparation
Q = correct_questions / 3.0 * 100
```

学识不是简单与100分线性相加，而要与当周难度比较：

```python
knowledge_fit = clamp(65 + (K - exam_difficulty) * 1.5, 0, 100)
academic_score = (
    0.55 * knowledge_fit
    + 0.20 * P
    + 0.10 * Q
    + 0.08 * W
    + 0.07 * H
)
conduct_score = 0.65 * M + 0.20 * T + 0.15 * A
fatigue_penalty = max(0, 5 - stat_stamina) * 2.5 + max(0, 6 - stat_health) * 2
exam_score = clamp(
    0.72 * academic_score
    + 0.28 * conduct_score
    + conduct_choice_bonus
    - fatigue_penalty
    - exam_weather_penalty,
    0, 100
)
```

- `conduct_choice_bonus` 范围 -8至+4；作弊成功也不得成为稳定最优解。
- `exam_weather_penalty`：普通天气0；小雨/江雾1；寒潮2；雨夹雪3。拥有足够保暖、提前查看预报并夜间按时返宿可抵消。
- 学识和道德分别直接控制卷面与学行，二者合计占总评的主体。高学识低道德无法满绩；高道德但没有学习也不能凭品行取得高分。

### 3.7 随机事件数据校验

事件数据必须通过自动校验：

```python
def validate_event(event):
    assert event["id"]
    assert event["choices"]
    for choice in event["choices"]:
        effects = choice.get("effects", {})
        flags = choice.get("set_flags", [])
        inventory = choice.get("inventory", {})
        relationships = choice.get("relationships", {})
        assert (
            any(v != 0 for v in effects.values())
            or any(v != 0 for v in inventory.values())
            or any(v != 0 for v in relationships.values())
            or len(flags) > 0
        ), f"{event['id']} has a consequence-free choice"
```

## 6. 事件引擎与防重复

事件筛选顺序：固定史实事件 → 已约定人物事件 → 符合地点/时段/天气/前置的随机事件 → 地点基础互动。

```python
def choose_event(location, period):
    eligible = [e for e in EVENTS if event_is_eligible(e, location, period)]
    for e in eligible:
        e["runtime_weight"] = e["weight"]
        if e["id"] in recent_events: e["runtime_weight"] *= 0.15
        if e["id"] not in seen_events: e["runtime_weight"] *= 1.6
        if current_weather in e.get("preferred_weather", []): e["runtime_weight"] *= 1.5
    return weighted_pick(eligible) if eligible else fallback_for(location, period)
```

- `recent_events` 保存最近 8 个事件。
- 同一随机事件默认冷却 7 日；天气全局事件冷却 5-9 日。
- 竺可桢随机偶遇每次后冷却 5 日；一周最多一次；单周目随机出现 4-6 次。
- 不允许玩家在同一地点反复进出刷校长。地点选择后才抽取事件，加载存档不得重新掷骰。
