# 《负笈西行：建德四十五日》
# Codex 监工返工令与强制验收标准

**文件定位：** 本文件是对现有 Codex 实现的强制纠偏补丁。  
**执行优先级：** 原指导书 → 新玩法补丁 → 本监工返工令。  
**冲突处理：** 任何旧实现与本文件冲突时，必须以本文件为准。  
**适用项目：** “搓游戏儿” / 建德四十五日 Ren’Py 项目。

# 0. 立即停止“表面完成”

当前实现存在以下严重问题：

1. 随机事件选项与剧情不匹配。
2. 大量按钮使用“动手解决 / 核对记录 / 先照料人”这类万能模板。
3. 玩家点击后缺少具体反馈，只看到属性数字变化。
4. 社团系统只有入口和按钮，没有实际玩法。
5. 此前提出的大学经营、人物羁绊、课堂互动、天气地图、旧物收集等系统没有真正落地。
6. 天气仅作为文字或变量存在，建德大地图没有雨、雾、寒潮等视觉变化。
7. 考试结果与玩家平日学习、道德、求实、出勤的联系不够强。
8. 部分“事件”只是标题、短句和三个套模板按钮，本质上仍是空壳。

从本文件开始，Codex不得再以“界面已经出现”“变量已经建立”“按钮可以点击”作为完成依据。

> 功能存在，不等于玩法成立。  
> 按钮能按，不等于玩家进行了选择。  
> 属性变化，不等于系统给出了反馈。  
> 地图能显示，不等于天气系统完成。

# 1. 截图中事件的直接整改意见

截图事件：

> **迟到的仪器船**  
> 暮色将近，载着仪器的民船才靠岸。所有人临时排成一列接力。  
> 选项：  
> - 动手解决  
> - 核对记录  
> - 先照料人

该实现不合格，原因如下：

- “动手解决”没有说明玩家到底做什么；
- “核对记录”与“先照料人”都是从通用选项池复制的抽象词；
- 三个选项没有体现仪器船、天色将晚、船只靠岸、仪器防潮等具体矛盾；
- 玩家无法预判选择的伦理与资源取舍；
- 若选择后只显示“实务+2”“道德+2”，仍不构成完整反馈。

## 1.1 必须替换为以下写死版本

### 事件ID

`PORT_LATE_INSTRUMENT_BOAT_01`

### 标题

**迟到的仪器船**

### 触发条件

- 地点：梅城码头
- 时段：晚间
- 日期：Day 8—Day 30
- 天气：阴、雨、雾
- 冷却：12天
- 前置：`classroom_unlocked = true`
- 不可与“码头疏散警报”同回合触发

### 正文

暮色已经压到江面上，远处船影才从薄雾中慢慢浮出来。船工撑着篙，将一艘吃水很深的民船靠向码头。舱里装的是理学院和工学院急等使用的仪器，外层木箱在水汽中泛着暗光，其中两只箱角已经被雨水打湿。顾明川招呼学生们排成一列，准备趁天完全黑下去以前把仪器送进仓房。可校务处送来的接收清单少了一页，船上又有一名年长船工在靠岸时扭伤了脚。所有人都看向你：是先抢时间卸货，先查清箱号，还是先处理伤员？

### 选项A：先组织防潮卸货

**按钮：**

> 先铺油布，把受潮的仪器箱抢运上岸。

**固定反馈：**

你让两名同学把码头备用的油布铺在木板上，又按箱角颜色将易受潮的仪器排在最前。顾明川起初催得很急，见你没有一味图快，而是先把转运路线清出来，便立即配合你调整接力顺序。最后一只箱子抬进仓房时，天色已经全暗，但受潮没有继续扩大。清点时仍发现一只箱号无法确认，这个问题被留到次日校务处处理。

**固定数值：**

- 实务 `+4`
- 校园秩序 `+3`
- 体力 `-2`
- 健康：雨天额外 `-1`
- 顾明川信任 `+3`

**固定后续：**

- 设置 `flag_instrument_boxes_saved = true`
- 次日校务办公处提高“补查箱号”事件权重
- 若无雨具，深夜返宿触发“湿透的袖口”反馈

### 选项B：先封存现场并核对清单

**按钮：**

> 暂停搬运，逐箱记下编号和封条状态。

**固定反馈：**

你请大家先把箱子留在船舱和岸边油布覆盖区，不再继续往仓房搬。有人抱怨天快黑了，再拖下去只会更麻烦。你没有争辩，只拿来纸笔，从船头第一只箱子开始核对编号、封条、受潮位置和接收人。缺失的一页清单最终在船工的油布包里找到，上面还注明一件精密仪器不能倒置。若刚才直接接力搬运，它很可能已被横放。大家重新动手时虽多花了时间，却没有再出现去向不明的箱子。

**固定数值：**

- 求实 `+4`
- 学识 `+1`
- 实务 `+2`
- 体力 `-1`
- 校园秩序 `+2`
- 急躁学生关系 `-1`
- 校务处信任 `+3`

**固定后续：**

- 设置 `flag_instrument_manifest_verified = true`
- 未来“成绩册误记”“书箱编号不符”事件检定难度下降
- 本周周考学行评定附加分 `+1`

### 选项C：先安置受伤船工，再调人接货

**按钮：**

> 先扶伤员进棚，请校务处再派一组学生来。

**固定反馈：**

你没有让扭伤脚的船工继续坐在湿冷的船沿，而是和周顺安一起将他扶进码头边的棚屋。民居里的老人送来热水，校务处也临时调来四名学生接替搬运。仪器上岸比原计划更晚，两只木箱必须留在码头值守到次日早晨，但船工的伤势没有加重。第二天，他托人送来一小段新麻绳，说码头上愿意先照看人的学生，以后遇到急船，大家也愿意多帮一把。

**固定数值：**

- 道德 `+4`
- 人望 `+3`
- 心志 `+1`
- 校园秩序 `-1`
- 物资转运进度 `-2`
- 船工群体信任 `+4`

**固定后续：**

- 设置 `flag_boatman_helped = true`
- 解锁一次码头紧急事件的NPC自动援助
- 次日早晨码头产生“夜留木箱”续接事件
- 若次日不处理，校园秩序再 `-2`

# 2. 83个随机事件必须逐条写死

## 2.1 禁止通用选项池

立即删除或停用以下逻辑：

- 根据事件标签自动生成“动手解决”
- 自动生成“核对记录”
- 自动生成“先照料人”
- 自动生成“认真完成”
- 自动生成“暂时离开”
- 自动生成“请求帮助”

这些词可以偶尔出现在具体句子中，但不得作为跨事件复用的万能按钮。

以下类型代码必须删除：

```python
if "practice" in tags:
    choice = "动手解决"
if "truth" in tags:
    choice = "核对记录"
if "morality" in tags:
    choice = "先照料人"
```

## 2.2 每个事件至少包含三个唯一选项

83个事件共至少需要：

> `83 × 3 = 249` 个写死的选择分支。

每个选项必须：

1. 写明玩家采取的具体行动；
2. 与当前地点、人物、天气、物件直接相关；
3. 玩家点击前能够理解大致取舍；
4. 点击后出现不少于50字的具体反馈；
5. 至少造成一种非零结果；
6. 后果可以是属性、关系、资源、世界状态、任务旗标或下次事件权重；
7. 同一事件的三个选项不能只是同一件事的语气变化。

## 2.3 普通事件文本标准

### 开场正文

- 建议100—180字；
- 不得少于80个汉字；
- 必须交代时间、地点、眼前问题；
- 至少写出一个具体物件或人物动作；
- 天气或环境必须参与情境。

### 每个选择反馈

- 建议60—120字；
- 不得少于50个汉字；
- 必须说明玩家做了什么、NPC如何回应、事情如何收束、哪项后果被埋下。

# 3. 每次点击必须给出四层反馈

## 第一层：剧情反馈

显示完整结果文本，不少于50字。

## 第二层：人物反馈

至少出现一种：

- NPC即时对白；
- NPC表情变化；
- NPC关系提示；
- 无NPC时用环境变化或主角札记代替。

## 第三层：数值反馈

必须明确显示：

```text
实务 +4
校园秩序 +3
体力 -2
顾明川信任 +3
```

## 第四层：后果反馈

例如：

```text
【后续影响】缺失的箱号将在次日校务办公处继续追查。
```

隐藏属性可用语义反馈：

```text
【沈砚舟札记】没有查清以前，不宜急着把猜测写进清单。
```

# 4. 社团系统必须彻底重做

社团不得再是“加入—点击活动—属性增加”。

每个社团必须拥有：

- 加入剧情；
- 固定成员；
- 每周活动；
- 专属资源；
- 至少一条三阶段任务线；
- 一项需要玩家实际选择或操作的互动；
- 成功、部分成功和失败反馈；
- 与考试、经营、人物或日报系统的联系。

## 4.1 学术互助会

每次活动必须从以下玩法中抽取一项：

- 三题小测；
- 纠正同学解题过程；
- 选择讲解顺序；
- 整理一页受潮讲义；
- 判断一条结论是否有证据支持。

### 示例：给周顺安讲一道比例题

情境：周顺安把运送木料的数量抄在纸上，却不明白为什么三辆车各装八捆不是“十一捆”。纸面已经被他擦破一角。

#### 选项A

> 从三组八根木条开始画图给他看。

- 学识 `+2`
- 道德 `+2`
- 周顺安信任 `+3`
- 体力 `-1`

#### 选项B

> 直接告诉他计算规则，让他先把答案记住。

- 学识 `+1`
- 实务 `+1`
- 教学质量标记 `-1`

#### 选项C

> 请他用码头搬运的经历自己举一个例子。

- 创新 `+2`
- 学识 `+2`
- 周顺安信任 `+2`
- 心志 `+1`

三个选项都必须有固定结果文本。

## 4.2 工读互助组

必须包含：

- 排字；
- 搬运；
- 送报；
- 统计售报收入；
- 救济申请核对；
- 贫困学生工时安排。

每次活动必须有现实矛盾，例如学习时间与工读冲突、收入与救济冲突、连续代班、账目差额。

## 4.3 修缮队

必须加入真实步骤选择。

例如修补教室窗框时，在：

- 先拆腐木；
- 临时塞布；
- 整框加固；

之间选择。不同方式影响木材、工具耐久、教室保暖、本周考试状态和校园秩序。

## 4.4 新闻社

Day20后开放。

必须涉及：

- 消息来源；
- 交叉核实；
- 标题选择；
- 校对；
- 排版；
- 是否刊登未经证实的消息；
- 是否为困难学生保留工读岗位。

选择影响求真、报纸可信度、售报量、居民信任和传言事件。

# 8. 周考必须与长期属性强绑定

## 8.1 固定考试日

- Day1：摸底测验，不计GPA；
- Day8、15、22、29、36、43：正式周考；
- 固定占用早晨行动；
- 逃课后不得无代价补考。

## 8.2 总分公式

所有值转为0—100：

```text
周考总分 =
实际答题正确率 × 35%
+ 学识 × 35%
+ 道德 × 15%
+ 求实 × 5%
+ 本周准备度 × 5%
+ 出勤率 × 3%
+ 身体与心志状态 × 2%
```

随机浮动最多 `-2 至 +2`。

## 8.3 GPA标准

| 总分 | GPA |
|---|---:|
| 95—100 | 5.0 |
| 90—94 | 4.5 |
| 85—89 | 4.0 |
| 80—84 | 3.5 |
| 75—79 | 3.0 |
| 70—74 | 2.5 |
| 60—69 | 2.0 |
| 50—59 | 1.0 |
| 0—49 | 0 |

## 8.4 5.0额外门槛

必须同时满足：

- 学识 `>=18/20`
- 道德 `>=18/20`
- 求实 `>=8/10`
- 本周准备度 `>=85`
- 出勤率 `>=90%`
- 实际题目正确率 `>=80%`
- 无作弊、抄袭、伪造记录
- 健康不低于3

否则最高4.5。

## 8.5 作弊后果

### 未被发现

- 道德 `-4`
- 求实 `-3`
- `exam_dishonesty_count += 1`
- 本次最高GPA 3.5
- 竺可桢印象下降

### 被发现

- 当次GPA `0`
- 道德 `-6`
- 人望 `-4`
- 学术互助会资格暂停一周
- Day45最佳彩蛋失效

## 8.6 结算必须说明来源

例如：

```text
本次周考：82分 / GPA 3.5

实际答题：29.8 / 35
学识积累：27.9 / 35
学行评定：11.3 / 15
求实与准备：7.2 / 10
出勤与状态：5.8 / 5（含奖励上限修正）
```
