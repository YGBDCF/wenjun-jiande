# 《负笈西行：建德四十五日》美术史料台账

## 竺可桢故居（梅城府前街孙宅）

- 游戏用途：45日自由探索中的重点地点；竺可桢低频、高权重事件发生地。
- 现代实拍：`game/images/meicheng_45/references/zhu_residence_gate_modern.png`
- 史料文档照片：`game/images/meicheng_45/references/historical_meicheng_photo.jpeg`
- 1937复原图：`game/images/meicheng_45/locations/zhu_residence_1937.png`
- 建筑识别要点：
  - 中央狭窄门洞与三层石台阶。
  - 灰白砖墙，两侧红褐色竖向砖带。
  - 顶部起伏山花与左右砖雕。
  - 中央石额“八文涵”。
- 复原处理：
  - 删除现代铭牌、二维码、监控、电子屏和现代建筑。
  - 保留门楼尺度，不夸张改造成大型徽派宅院。
  - 以1937年秋雨后的石板路、木箱、油纸伞与油灯补足时代环境。
- 资料依据：
  - 杭州文史网《文军的长征——抗战期间浙大西迁建德点滴》
  - 杭州文物活化利用示范案例《浙大西迁旧址》
  - 用户提供的现场实拍与《建德资料整理》

## 使用原则

1. 历史照片用于建筑比例、构件、路线和环境考据，不直接把现代展馆照片当1937年画面。
2. 生成图不得添加无法核实的校牌、现代校徽旗帜或现代宣传用语。
3. 图片本身不焊死剧情正文；人物、姓名、选项、任务和档案均由Ren'Py动态显示。
4. 每张正式背景保留对应参考图、来源说明和生成版本号。
